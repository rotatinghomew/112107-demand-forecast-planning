# 社区居家服务需求预测与可承接计划

以下资料为合成记录，不含实际个人信息。文件以 UTF-8 编码，普通字段含日期或本地时间（东八区），分号表示同一字段的多值。空值表示在该记录中未提供，不自动当零。表内的凭据编号用于核对记录归属。

## 数据来源

- `data/accounts.csv`：家庭的真实服务承诺与时点不同的改变；frequency 是每周次数，minutes 是每次派班计入分钟。
- `data/shift_calendar.csv`：较早确认的固定班和数量可变的替代班，均按周一开始的一周记录，分钟为整周。
- `data/flex_agreements.csv`：已签可复用及条件约；临时班计划的替代班只对列出的适用周有效。
- `data/offers.csv`：承诺起始周、完整持续周期与采购。
- `data/planning_policy.csv`：计划验算需要的参数；区间覆盖和续约风险限额不是固定算法。
- `data/past_events.csv`：较早团组的逐项历史回执，末期有右删失。同一生效日可先收到到期、若干天后才收到续约结论。
- `data/history_cutoffs.csv`：各站采集覆盖止日为已可核观察长度，不是所有家庭结束日。

## 环境及检查

使用 Python 3.11.2 标准库，无需网络或额外安装。在项目目录可执行 `python3 -m unittest discover -s tests -v` 核对输入文件、表头与记录形状。各来源字段及记录数量见 `data-contract.json`。目前提供资料读取检查，不生成业务分析结果。
